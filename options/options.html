Groq API Key (BYOK)
Stored only in chrome.storage.local — never leaves your browser except in direct calls to Groq's API. Get a free key at console.groq.com.
Learning domain gate
When enabled, Groq reads the video title and returns one learning domain from the full catalog (all five defaults plus any custom lines you added). Recording runs only if that domain is in your allowed list (checkboxes + textarea). If Groq picks a domain you have not allowed yet, the popup offers Add domain & track. Requires a Groq API key. When this is on, it overrides the YouTube-only category filter below.
These strings must match what you want Groq to return — use clear, consistent wording.
Google Form URL
Paste the URL of your "Track my learning" Google Form. Use the public /viewform URL — not the editor URL.
YouTube
Uses YouTube’s category metadata only when Learning domain gate is off. When the gate is on, Groq decides instead. If the gate is off, enabling this limits tracking to Education, Science & Technology, and How-to & Style.
Uses category metadata from the watch page. If YouTube does not expose a category yet, tracking may start briefly and then stop once the category is known.
Sync Preferences
Control how the form is filled.
When off, the form fills but stays open for you to review before clicking Submit.
Backup & restore
Download your data as JSON or restore from a file. Backups include sessions, streak, insights, goals, form URL, and Groq settings — keep exports private if they contain your API key.
Only keys present in the file are written; other stored keys are left as-is.
Danger Zone
