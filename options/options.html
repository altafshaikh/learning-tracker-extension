Bundled defaults (config/defaults.json)
Edit this file in the extension folder for your Form URL, model, and auto-submit. On load, empty fields in browser storage are filled from the file. The extension always reads settings from chrome.storage.local at runtime — the JSON file is only a template and seed.
Use this after you change config/defaults.json to overwrite Form URL / model / auto-submit in the browser from the file.
Groq API Key (BYOK)
Stored only in chrome.storage.local — never leaves your browser except in direct calls to Groq's API. Get a free key at console.groq.com.
Google Form URL
Paste the URL of your "Track my learning" Google Form. Use the public /viewform URL — not the editor URL.
Sync Preferences
Control how the form is filled.
When off, the form fills but stays open for you to review before clicking Submit.
Danger Zone
Permanently delete all tracked sessions from local storage.
