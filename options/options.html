Learning Tracker

Learning goals, Groq API key, and Google Form URL
Learning goals
These values are stored in chrome.storage.local and drive Total learned and progress everywhere: total = learned before + all time tracked by this extension. Change your hour target anytime.
Study you did before installing the extension (not double-counted with tracked sessions).
Groq API Key (BYOK)
Stored only in chrome.storage.local — never leaves your browser except in direct calls to Groq's API. Get a free key at console.groq.com.
Google Form URL
Paste the URL of your "Track my learning" Google Form. Use the public /viewform URL — not the editor URL.
Sync Preferences
Control how the form is filled.
When off, the form fills but stays open for you to review before clicking Submit.
Danger Zone
Permanently delete all tracked sessions from local storage.
